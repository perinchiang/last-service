# First playable

Current playable baseline: v0.1.1. The v0.1.2 diagnostic-panel implementation was rejected and reverted on 2026-11-17. See [the revised robot-vision direction](direction.md) for the intended optical presentation and the distinction between future design and existing gameplay.

An abandoned-human industrial world. A service robot awakens on a maintenance platform and is denied exit because a human supervisor is required. Break the security interlock, survive a brief encounter, and open the heavy gate.

One polished room; exploration alternates with combat. Desktop browser first, basic touch controls for phone playtesting. A short skippable in-engine awakening, one weapon, hovering security drones, an optional falling cargo hazard, and a gate opening sequence. No obligatory mirror puzzle. Reflective material is an optional part of lighting, not a game mechanic.

Stage checkpoints: (1) reproducible project and repository; (2) procedural room and cinematic; (3) full combat, sound, touch input and restart; (4) browser verification and GitHub Pages release.
