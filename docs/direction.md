# LAST SERVICE：机器人视觉与后续方向

更新：2026-11-17。本文区分用户要求、设计解释与待验证方案，不代表这些效果已经实现。

## Patrick 真正要的感觉

Patrick 的表达是：**“跃然纸上、跃然在玻璃上的感觉。”** 他指出被撤回的框“很像标题的 UI”，整体像在画面上贴了几张贴纸。

目标是让玩家从机器人的眼睛里看世界：文字、细线和识别标记仿佛由光形成，浮现在眼前的透明光学层上。场景始终是主体，信息是机器人正在感知和判断的痕迹。玩家应当感觉到“我的视觉系统开始工作了”，而不是“游戏打开了两块状态面板”。

**“玻璃上”描述的是信息的呈现感，不是要求摆一块玻璃材质的矩形卡片。** 给旧面板降低透明度、加背景模糊、霓虹边框或更多装饰线，并不能满足这个要求。也不必真的画出一副眼镜或整块玻璃的外沿。

## 明确保留的体验要求

- 苏醒时先躺着观察和分析，不立即坐起来或举枪。形成自己的目标之后，身体才行动。
- 视野偏左有小范围的思考过程：短句快速流动，有节奏地停顿；随后出现简短的 Python 风格调用。右侧随调用逐项返回环境、时间、温度、机体状态等结果。这里的“小框”是局部信息区域，不是带标题栏和实底背景的窗口。
- 工具调用、结果和行动之间有因果关系。先尝试联系值班主管，等待回应，联系失败后才建立寻找目标；不能一开场就把所有数值和结论填满。
- 普通前进、射击不逐条刷屏。日常摘要可以约 30 秒一条，但没有新信息时不必输出；剧情节点和重要发现才出现更完整的思考过程。
- 战斗中的信息不能抢夺操作权。开场可以有从容的观察和判断，交战时保持克制、简短和清晰。

## 视觉与动态的设计解释

以下是把上述感觉转成制作约束的解释，具体光感、位置和动效幅度仍需实际样段验证。

### 信息像光，场景保持可见

文字与线条本身发出克制的光，背景以透明为主。避免大面积深色底、磨砂矩形、完整封闭边框、标题栏、表格分隔和左右对称的仪表盘布局。需要组织信息时使用留白、短引线、局部角标和出现顺序。亮边与辉光是辅助，不能糊掉文字，也不能把画面染成一层强烈霓虹色。

不是把所有文字做得很淡来伪装透明：亮背景下仍需可读，可使用局部描边、轻微暗衬或自适应亮度，不以新增整块面板解决问题。

### 识别必须和眼前事物有关

扫描应当短暂指向场景中实际存在的灯、检修装置或目标。识别角标跟随被识别对象的屏幕位置；对象移出视野时不留下悬空标签。思考文字属于视野内的信息层，可以偏左稳定呈现，不要求所有内容都钉在世界坐标上。

若采用轻微视差或跟随延迟，应服务于空间感，不能晃动阅读内容、拖动准星或制造眩晕。动效不是越多越好。

### 让玩家看见一个过程

先出现感知线索，再短暂分析；脚本逐行生成，正在执行的调用有明确状态；结果在右侧随之返回，新的判断依赖该结果。遇到无响应时，等待和失败应看得见。最后确认目标，触发检修臂收回和身体起身。文字、光学标记、电子反馈声与机械动作共同表达这个过程。

单纯滚动控制台日志，或者播放与世界无关的代码雨，都不够。所谓“思考”是虚构机器人的剧情表现，不需连接真实大模型或执行任意 Python；实际机械动作由游戏逻辑驱动。

## 开场样段：用于对齐感觉，不是已批准的分镜

1. 黑暗中恢复视觉，仍躺在检修台上，看到上方灯与装置。可尝试轻微失焦后清晰的视觉恢复。
2. 局部扫描线和识别角标出现，左侧短句开始流动：视觉恢复、场景识别、没有操作员指令。
3. 左侧出现少量调用，依次读取环境、设施时钟并联系值班主管。右侧只在调用完成后返回对应结果。
4. 联系主管无响应，快速流动停下来，留下短而可读的判断：需要现场寻找操作员。
5. “寻找值班主管”成为目标。运动系统开始执行，检修装置收回，镜头随身体起身。信息自然收拢或淡出，玩家接管。

这段样例沿用已讨论的内容；具体台词、停顿时长、总长度及视觉参数均待确认。撤回版本使用的 10.8 秒、7.4 秒和固定面板尺寸不是后续硬性要求。

## 已讨论的游戏方向与当前实现分开记录

游戏仍以代码生成的封闭工业设施和第一人称动作体验为基础。通过射击设备改变战斗局面；已有吊箱是起点，新增区域应带来新的战斗选择。Patrick 愿意花数月打磨，但不希望投入 Blender 或 TRIPO 建模流程。

MK.04 作为维护脉冲器、机器人自身安全控制器在威胁迫近时触发自卫例外，是此前讨论的叙事方向。因为本次是整版回退，v0.1.2 新增的权限实现也已撤销，不能说它仍在当前游戏中生效。后续是否以及如何重做，应与新开场一起验证。

## 下一次制作如何验收

本轮到文档澄清为止，不自动开始重做。下一次获准制作时，先交付一段可实际运行的短样段，验证视觉和动作，再扩展完整状态与适配。

- 不读文字时，是否仍像机器人自己的视觉，而不是标题页或网页卡片？
- 透过信息，是否仍清楚看到场景？光感是否来自字与线，而非一大块背景？
- 是否能看懂“观察 → 判断 → 调用 → 结果 → 决定 → 行动”的关联？
- 动态扫描是否指向实际事物？身体动作是否在相应判断和调用之后发生？
- 手机上是否可读，且没有为了适配又退化成堆叠卡片？
