# v0.1.1 · 检修大厅美术迭代

BUILD a3a4c05f · 2026-11-16

[在线试玩](https://perinchiang.github.io/last-service/?v=a3a4c05f)

这一轮集中改进原有房间的空间、光影、武器和声音，任务仍然是检查终端、破坏联锁、抵抗六架安保机并打开出口。

- **空间**：仍在检修台上苏醒，检修台到隔离门的距离由约 10.5 拉长到 29.7 个场景单位。柱列、灯具、地面导轨形成连续透视，门改为内嵌的切角隔离门。
- **秩序与颜色**：两侧设备按建筑柱列排列，冷却设备有回接管道和标识，吊装箱连接顶部起重装置。主色收敛为冷灰与暗金属，橙色只留在少量功能提示处；没有恢复被否定的光锥。
- **地面**：反射随观看角度和涂层粗糙度变化，轻微模糊和静态微纹理保留门与灯具的倒影，不加入水波动画。
- **武器**：更细的机械枪身、开放式红点瞄具、导轨和散热槽。换弹时弹匣独立退出、插回，枪机独立动作；继续保持瞄具中心与射线准心重合。
- **声音**：程序生成的低频机械底噪、通风声、偶发远处机械声、短房间混响，以及按左右方向和距离处理的无人机、爆炸和开门音效。

电脑操作不变。手机仍为单点直接射击、长按约 240 毫秒开镜连射、松开退出。手机自动使用流畅画质，关闭实时平面反射与高成本后处理；若要观看倒影，可以在菜单选择“精细”。

全部几何、纹理、声音继续由代码生成，发布文件为约 634 KiB 的自包含 index.html，无需额外素材或运行时网络请求。

已通过 20 项 Node 检查，以及 16 项任务流程、16 项桌面/触屏输入、10 项场景/声音浏览器检查。已查看出生点、中段、侧面、换弹和手机竖屏画面。手机输入是在 Chrome 的同源 iframe 中验证，未进行实机 iPhone Safari 或 Windows 鼠标复测；声音检查确认合成输出、左右声道差异与混响尾音，不等同于主观耳机试听。

本轮没有纳入档案室、猎犬、后续剧情、载具或新的过场。
