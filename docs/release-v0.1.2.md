2026-11-17 · BUILD **63c9e84d** · 功能分支试玩版本

## 本轮可以玩到什么

- 启动后先仰躺扫描，不立即起身。左侧依次显示感知、工具调用、结果和判断，右侧逐项显示环境读数。
- “寻找值班主管”的目标建立后，检修装置才收回、平台下降，约 10.8 秒后交给玩家操作；可点击“跳过诊断”。
- MK.04 被明确为维护脉冲器。维护输出始终可用；安保威胁迫近时，由本机安全控制器开启临时自卫权限，清除威胁后收回。
- 战斗中的日志只报告重要变化，读完约 7 秒后退场。移动、射击只做低频摘要，没有行动就不填充日志。
- 手机竖屏压缩次要信息，并为触控按钮和中心准星留出空间。

这是现有一间大厅的打磨版本：门禁、两波无人机、吊箱和出口构成完整试玩闭环。本轮没有新增房间或敌人种类。设计约定见 [方向文档](direction.md)。

## 怎么试玩

打开仓库根目录的 `index.html`，或在项目内执行 `npm run dev` 后访问终端显示的地址。文件包含所有游戏资源；无需安装美术资源或连接后台。

电脑：WASD 移动，鼠标转向，右键瞄准，左键射击，E 操作，R 更换电容，Esc 暂停。手机：左摇杆移动、右侧拖动视角，单点射击，长按射击键开镜连射；横屏视野更宽。

这份说明对应功能分支。GitHub Pages 仍随 `main` 部署，合并发布前，线上链接不代表本次原型。

## 这次请重点体验

1. 开场能否让你理解：自己是一台维修机器人，正在寻找值班主管？
2. 进入战斗后，日志是在帮你理解情况，还是抢走注意力？
3. 面对无人机时，你是否愿意主动尝试吊箱，而不是一直站着射击？

下一轮根据这三个问题调整节奏、敌人位置、机关收益和攻击反馈，再决定何时增加新区域。
